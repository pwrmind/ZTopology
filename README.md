# 👀 Z-Topology: Спиральные LEGO-колодцы для компьютерного зрения

Экспериментальная топология нейросети, которая отказывается от классической свертки (CNN) в пользу пространственно-последовательного анализа пикселей. Архитектура построена на концепции **"винтовых LEGO-колодцев"**, где локальные окна изображения сканируются по спирали с помощью сверхлегких ячеек памяти шириной 2.

Проект демонстрирует, что чистая геометрия обхода пикселей в сочетании с накоплением контекста способна конкурировать со стандартными CNN на задаче распознавания образов (MNIST), используя при этом прозрачную и простую математику.

---

## 💡 Идея и Архитектура

Классические сверточные сети (CNN) обрабатывают локальное окно \(3 \times 3\) линейно: пиксели просто умножаются на веса фильтра и складываются. При этом теряется внутреннее направление градиента и локальная последовательность.

**Z-Топология работает иначе:**
1. Изображение разбивается на независимые "колодцы" размером \(3 \times 3\) пикселя.
2. Внутри каждого колодца запускается **винтовая Z-лесенка** (обход по спирали от правого нижнего угла строго в центр).
3. Каждый шаг лесенки (шириной 2) принимает текущий пиксель и "мысли" от предыдущего шага, бережно протаскивая локальный контекст.

```text
Порядок обхода окна 3х3 (Спираль):
  [4] [5] [6]        8 -> 7 -> 6
  [3] [0] [7]   -->  3 -> 0 -> 1
  [2] [1] [8]        2 -> 5 -> 4 (Финиш в центре)
```

### Математика LEGO-блока (Чистый Z-Step)
Вместо использования тяжелых стандартных ячеек (вроде GRU или LSTM), Z-топология опирается на абсолютно прозрачный шаг без скрытых гейтов:

$$h_{new} = \text{ReLU}(W_x \cdot x_{pixel} + W_h \cdot h_{previous})$$

Где $x_{pixel}$ — значение текущего пикселя в спирали, а $h_{previous}$ — вектор памяти предыдущего шага.

## 📊 Результаты эволюции архитектуры

Модель тестировалась на датасете **MNIST** (60 000 тренировочных картинок, 10 000 тестовых) в течение всего **5 эпох** обучения на обычном процессоре (`cpu`).


| Версия архитектуры | Пиковая точность (Test Accuracy) | Динамика и особенности |
| :--- | :---: | :--- |
| **V1 (Базовая с GRUCell)** | 96.95% | Быстрый старт, но логика скрыта внутри "черного ящика" GRU. |
| **V2 (Чистый LEGO-шаг)** | 96.12% | Математика очищена. Проявился эффект легкого переобучения. |
| **V3 (LEGO + Стабилизация)** | **97.72%** | **Финальная версия. Добавлены Dropout и LayerNorm. Стабильный рост.** |

Финальная точность в **97.72%** на одном экспериментальном слое доказывает жизнеспособность геометрии спиральных колодцев. Сеть не зазубривает пиксели, а выделяет универсальные геометрические законы линий и изгибов.

## 🚀 Быстрый запуск

Проект полностью автономен и готов к запуску. Менеджер пакетов `uv` автоматически скачает PyTorch и датасет MNIST при первом старте.

1. Клонируйте репозиторий или создайте папку с проектом.
2. Убедитесь, что у вас установлен `uv`. Если нет, установите одной командой:
   ```bash
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh | iex"
   ```
3. Запустите обучение и валидацию сети:
   ```bash
   uv run main.py
   ```

## 🗂️ Структура кода (`main.py`)

* `LegoZStep`: Класс, описывающий чистую математику шага лесенки шириной 2.
* `SpiralLegoWell`: Слой, который нарезает картинку на колодцы $3 \times 3$ и параллельно закручивает их по спирали с помощью `unfold`.
* `ZTopologyNet`: Финальная сборка сети, объединяющая Z-слой, слой нормализации `LayerNorm` и классификатор с защитой `Dropout(0.2)`.

---

## 🔮 Перспективы развития
* **Фрактальная многослойность:** Построение каскада из Z-слоев (например, первый слой сжимает $30\times30 \rightarrow 10\times10$, второй $12\times12 \rightarrow 4\times4$).
* **Смена траектории:** Эксперименты с обходом змейкой (зигзагом) или раскручиванием спирали из центра наружу.
* **Перенос на другие данные:** Применение Z-топологии в задачах OCR (распознавание рукописного текста) и анализе спектрограмм звука.
